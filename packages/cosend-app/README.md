# cosend-app

This name is an alias. The Cosend Node SDK is published as [`cosend`](https://www.npmjs.com/package/cosend); this package re-exports it, so `npm install cosend-app` and `import { Cosend } from "cosend-app"` work the same. Use `cosend` in new code. Docs at https://cosend.app/docs/api. MIT.
